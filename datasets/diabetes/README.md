### Diabetes

**Fonte:** [https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset](https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset)

Este conjunto de dados contém características clínicas e demográficas de pacientes, com indicação de diagnóstico de diabetes. O objetivo é prever a presença de diabetes a partir de fatores de saúde e histórico.

- `gender`: gênero do paciente.
- `age`: idade do paciente.
- `hypertension`: indica presença de hipertensão.
- `heart_disease`: indica presença de doença cardíaca.
- `smoking_history`: histórico de tabagismo.
- `bmi`: índice de massa corporal.
- `HbA1c_level`: nível de hemoglobina glicada.
- `blood_glucose_level`: nível de glicose no sangue.
- `diabetes`: indica diagnóstico de diabetes.

A variável-alvo é `diabetes`, caracterizando um problema de **aprendizado supervisionado do tipo classificação binária**.
