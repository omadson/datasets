### MPG

**Fonte:** [https://data.world/dataman-udit/cars-data](https://data.world/dataman-udit/cars-data)

Este conjunto de dados contém informações de automóveis, como consumo, cilindros, deslocamento, potência, peso, aceleração, ano, origem e nome do modelo. Ele é usado com frequência para estudar eficiência de combustível.

- `mpg`: consumo em milhas por galão.
- `cylinders`: número de cilindros.
- `displacement`: deslocamento do motor.
- `horsepower`: potência.
- `weight`: peso do veículo.
- `acceleration`: aceleração.
- `model_year`: ano do modelo.
- `origin`: origem do veículo.
- `name`: nome do veículo.

A variável-alvo é `mpg`, caracterizando um problema de **aprendizado supervisionado do tipo regressão**.
