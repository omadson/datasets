### Laptop Price

**Fonte:** [https://www.kaggle.com/datasets/muhammetvarl/laptop-price](https://www.kaggle.com/datasets/muhammetvarl/laptop-price)

Este conjunto de dados contém especificações técnicas e preços de notebooks, incluindo fabricante, modelo, tela, processador, memória, armazenamento, GPU e sistema operacional. Ele é útil para modelagem de preço de produtos eletrônicos.

- `laptop_ID`: identificador do notebook.
- `Company`: fabricante.
- `Product`: nome do produto.
- `TypeName`: categoria do notebook.
- `Inches`: tamanho da tela em polegadas.
- `ScreenResolution`: resolução e tipo de tela.
- `Cpu`: processador.
- `Ram`: memória RAM.
- `Memory`: armazenamento.
- `Gpu`: placa gráfica.
- `OpSys`: sistema operacional.
- `Weight`: peso.
- `Price_euros`: preço em euros.

A variável-alvo é `Price_euros`, caracterizando um problema de **aprendizado supervisionado do tipo regressão**.
